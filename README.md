## 📖 Overview

**Max Extrusions** is a production-ready corporate website designed for B2B manufacturing excellence. Built for a leading plastic products manufacturer, this platform showcases industrial capabilities, facilitates lead generation, and establishes digital credibility in the manufacturing sector. The site features an optimized product catalog, client portfolio, infrastructure showcase, and enterprise-grade contact management.

### Why This Platform?

| Feature | Description |
|---------|-------------|
| 🎯 **B2B-Focused Design** | Professional UI tailored for architects, OEMs, contractors, and industrial buyers |
| 🚀 **Performance First** | Next.js 15 App Router with optimized loading, SEO, and Core Web Vitals |
| 📊 **Lead Generation** | Integrated Formspree contact forms with Google Sheets automation |
| 🎨 **Modern UX** | Framer Motion animations with industrial-grade aesthetic |
| 📱 **Responsive** | Seamless experience across desktop, tablet, and mobile devices |
| ⚡ **Production Ready** | TypeScript, ESLint, and best practices for scalable architecture |

## 📥 Installation

### Prerequisites

Ensure you have the following installed:
- **Node.js** 18.x or higher
- **npm** or **yarn** package manager
- **Git** for version control

### 1️⃣ Clone the Repository

\`\`\`bash
git clone https://github.com/yourusername/max-extrusions.git
cd max-extrusions
\`\`\`

### 2️⃣ Install Dependencies

\`\`\`bash
npm install
# or
yarn install
\`\`\`

### 3️⃣ Environment Configuration

Create a \`.env.local\` file in the root directory:

\`\`\`bash
# Formspree Configuration
NEXT_PUBLIC_FORMSPREE_ID=your_formspree_form_id

# Google APIs (if using Sheets integration)
GOOGLE_SHEETS_API_KEY=your_google_api_key
GOOGLE_SHEETS_SPREADSHEET_ID=your_spreadsheet_id

# Site Configuration
NEXT_PUBLIC_SITE_URL=http://localhost:3000
\`\`\`

> 🔑 **Getting API Keys:**
> - Formspree: [https://formspree.io/](https://formspree.io/)
> - Google Sheets API: [Google Cloud Console](https://console.cloud.google.com/)

### 4️⃣ Start Development Server

\`\`\`bash
npm run dev
\`\`\`

Navigate to [http://localhost:3000](http://localhost:3000)

<details>
<summary>🐳 Docker Setup (Optional)</summary>

\`\`\`bash
# Build Docker image
docker build -t max-extrusions .

# Run container
docker run -p 3000:3000 max-extrusions
\`\`\`

</details>

<details>
<summary>📋 Detailed Setup Instructions</summary>

### Additional Configuration Steps

1. **Configure Contact Forms:**
   - Sign up at [Formspree](https://formspree.io/)
   - Create a new form
   - Copy the form ID to \`.env.local\`

2. **Setup Google Sheets (Optional):**
   - Enable Google Sheets API in Cloud Console
   - Create service account credentials
   - Share target spreadsheet with service account email

3. **Customize Products:**
   - Edit \`/lib/products.ts\` to add/modify products
   - Add product images to \`/public/images/products/\`

4. **Update Company Information:**
   - Modify content in page components
   - Update client logos in \`/public/images/clients/\`

</details>

<details>
<summary>⚠️ Common Setup Issues</summary>

| Issue | Solution |
|-------|----------|
| Port 3000 already in use | Run \`npm run dev -- -p 3001\` |
| Module not found errors | Delete \`node_modules\` and reinstall |
| Tailwind styles not loading | Restart dev server after config changes |
| Image optimization errors | Check Next.js image formats and sizes |
| TypeScript errors | Run \`npm run lint\` to identify issues |

</details>

<details>
<summary>🎛️ Advanced Configuration</summary>

### Customizing Product Data

Edit \`/lib/products.ts\`:

\`\`\`typescript
export interface Product {
  id: string;
  name: string;
  slug: string;
  description: string;
  image: string;
  categories: string[];
  specifications?: string[];
  features?: string[];
}
\`\`\`

### Form Configuration Options

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| \`formId\` | string | Formspree form identifier | Required |
| \`validationMode\` | string | Form validation timing | \`onBlur\` |
| \`submitTimeout\` | number | Submission timeout (ms) | \`30000\` |
| \`successMessage\` | string | Custom success message | Default |

## 🔌 API Documentation

### Contact Form Endpoint

**Endpoint:** \`/api/contact\`

**Method:** \`POST\`

**Request Body:**
\`\`\`json
{
  "name": "string",
  "email": "string",
  "phone": "string",
  "company": "string",
  "message": "string",
  "productInterest": "string"
}
\`\`\`

**Response:**
\`\`\`json
{
  "success": true,
  "message": "Form submitted successfully"
}
\`\`\`

### Contact Export Endpoint

**Endpoint:** \`/api/contacts/export\`

**Method:** \`GET\`

**Description:** Export submitted contacts to CSV/Excel format

**Authentication:** Required (if implemented)

> 📘 **Note:** Form submissions are primarily handled by Formspree integration. API routes provide additional flexibility for custom workflows.
